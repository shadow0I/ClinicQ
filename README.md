# ClinicQ

Queue Prediction & Crowd Management Engine

## Project Description

ClinicQ is a clinic queue management application
that predicts patient waiting times using
clinic-specific consultation history.

## Technology Stack

- React
- Tailwind CSS
- Python FastAPI
- PostgreSQL
- NumPy
- pandas
- Server-Sent Events

## Main Modules

1. Staff Dashboard
2. Patient Queue Tracking
3. Waiting Time Prediction
4. Emergency and Delay Management
5. Waiting Room Crowd Measurement

## Project Status

Development in progress.

## Data Policy

The prototype uses synthetic demonstration data.
Do not upload real patient records or credentials.
